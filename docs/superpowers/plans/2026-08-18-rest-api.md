# Core REST API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add authenticated REST CRUD endpoints for users, recipes, comments, supply items, and RFQs to the existing Fastify/PostgreSQL application, with strict Zod validation, centralized errors, and native Node integration tests.

**Architecture:** Keep route, controller, and service modules explicit by resource. Route pre-handlers run strict Zod parsing and Bearer authentication; controllers only translate validated requests to HTTP responses; services perform Prisma queries and ownership checks. Use Node's `crypto` module for password hashing and signed stateless tokens, avoiding another dependency or database migration.

**Tech Stack:** Node.js ESM, Fastify 5, Prisma 7 with PostgreSQL, Zod 4, Node `crypto`, and the native `node:test` runner.

**Spec:** `docs/superpowers/specs/2026-08-18-rest-api-design.md`

## Global Constraints

- Keep the existing ESM package configuration and native `node:test` command.
- Reuse the existing Prisma schema and pooled client; do not add a migration.
- Add no runtime dependency for authentication, validation, routing, or tests.
- Every request body, route-parameter object, and supported query object uses a strict Zod schema before controller logic.
- Mutations and `GET /api/auth/me` require `Authorization: Bearer <token>`; collection and item reads remain public.
- Only the authenticated owner may mutate or delete a user, recipe, comment, supply item, or RFQ.
- Never return `passwordHash`, token signatures, database errors, or stack traces.
- Return direct resources with `200` for reads/updates, `201` for creates, and `204` for deletes.
- Keep the stable `{ error: { code, message } }` response contract for all errors.
- Use unique database records and cleanup in `finally` blocks in integration tests.
- Run `npm run test` before claiming completion.

**Interfaces:**
- `AppError(statusCode, code, message)` is the public error type consumed by `server/app.js`.
- `mapError(error)` maps `AppError`, Prisma `P2002`, `P2003`, and `P2025` errors to public errors and returns `null` for unknown failures.
- `validate({ body, params, query } = {})` returns a Fastify `preHandler` that stores parsed values in `request.validated` and throws `400 VALIDATION_ERROR` on any failed Zod parse.
- `hashPassword(password)`, `verifyPassword(password, encodedHash)`, `signToken(userId, { secret, now })`, and `verifyToken(token, { secret, now })` are asynchronous or synchronous as appropriate and use only `node:crypto`.
- `createAuthenticate({ secret })` attaches a public database user to `request.user` or throws `401 UNAUTHORIZED`.
- `createRequireRole(role)` rejects an authenticated user with the wrong role using `403 FORBIDDEN`.

Create `server/errors.js`:

```js
export class AppError extends Error {
  constructor(statusCode, code, message) {
    super(message);
    this.name = 'AppError';
    this.statusCode = statusCode;
    this.code = code;
  }
}

export function mapError(error) {
  if (error instanceof AppError) return error;
  if (error?.code === 'P2002') return new AppError(409, 'CONFLICT', 'Resource already exists');
  if (error?.code === 'P2003') return new AppError(409, 'CONFLICT', 'Resource is still in use');
  if (error?.code === 'P2025') return new AppError(404, 'NOT_FOUND', 'Resource not found');
  return null;
}

export function badRequest(message = 'Bad request') {
  return new AppError(400, 'BAD_REQUEST', message);
}

export function unauthorized(message = 'Authentication required') {
  return new AppError(401, 'UNAUTHORIZED', message);
}

export function forbidden(message = 'You do not have permission to perform this action') {
  return new AppError(403, 'FORBIDDEN', message);
}

export function notFound(message = 'Resource not found') {
  return new AppError(404, 'NOT_FOUND', message);
}

export function assertOwner(actorId, ownerId) {
  if (actorId !== ownerId) throw forbidden();
}
```

- [ ] **Step 4: Add strict request validation**

Create `server/validation.js`:

```js
import { AppError } from './errors.js';

function parseRequestPart(schema, value) {
  const result = schema.safeParse(value);
  if (!result.success) throw new AppError(400, 'VALIDATION_ERROR', 'Request validation failed');
  return result.data;
}

export function validate({ body, params, query } = {}) {
  return async (request) => {
    const validated = request.validated ?? {};
    if (body) validated.body = parseRequestPart(body, request.body);
    if (params) validated.params = parseRequestPart(params, request.params);
    if (query) validated.query = parseRequestPart(query, request.query);
    request.validated = validated;
  };
}
```

```js
let active = createDatabaseClient();
export let prisma = active.prisma;
let closePromise;

function ensureActiveClient() {
  if (!closePromise) return;
  active = createDatabaseClient();
  prisma = active.prisma;
  closePromise = undefined;
}

export function registerDatabase(app) {
  ensureActiveClient();
  app.addHook('onClose', async () => {
    closePromise ??= closeActiveClient(active);
    await closePromise;
  });
}
```

client/pool pair in the close promise so a later recreation cannot alter an

```js
async function request(method, url, { body, token } = {}) {
  const response = await app.inject({
    method,
    url,
    headers: {
      ...(body ? { 'content-type': 'application/json' } : {}),
      ...(token ? { authorization: `Bearer ${token}` } : {})
    },
    ...(body ? { payload: JSON.stringify(body) } : {})
  });
  return { response, body: response.body ? JSON.parse(response.body) : null };
}

async function register(role = 'USER') {
  const suffix = randomUUID();
  const result = await request('POST', '/api/auth/register', {
    body: {
      email: `${suffix}@example.test`,
      password: 'Secret123!',
      name: `API User ${suffix.slice(0, 8)}`,
      handle: `@api_${suffix.replaceAll('-', '').slice(0, 20)}`,
      role
    }
  });
  assert.equal(result.response.statusCode, 201);
  createdUserIds.add(result.body.user.id);
  return result.body;
}
```
